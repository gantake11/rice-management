# rice-management (お米管理Webアプリ)

家庭内の米の在庫管理、および消費・贈答履歴を家族間でリアルタイムに共有・記録するためのWebアプリケーションです。

---

## 1. プロジェクト概要

### 背景
- これまで米の在庫管理や「いつ・誰（親戚など）に・どれくらい渡したか」「自宅でどれくらい消費したか」の記録を祖母が紙のノートで行っていました。
- 紙の管理では家族間でのリアルタイムな情報共有が難しく、記録漏れや過去データの参照に手間がかかるという課題がありました。
- 誰でも簡単に記録・参照でき、履歴が埋もれないようにWebアプリとしてデジタル化を目指します。

### 目的・提供価値
- **入力の手軽さ**: スマートフォンなどから手軽に入出庫（消費・贈答・補充）を記録。
- **閲覧性の確保**: 現在の在庫数と過去の利用履歴を一目で直感的に把握。
- **属人化の解消**: 米の在庫・流通状況を家族全員で可視化・共有し、適切な消費・配分を実現。

詳細な要件や背景については [doc/01_requirements/01_overview.md](doc/01_requirements/01_overview.md) を参照してください。
